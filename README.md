# SCOPEX Diagnostics Premium Website

Next.js App Router website for SCOPEX Diagnostics with premium branding, lead generation flows, and integrations.

## Stack

- Next.js (App Router, SSR, SEO)
- Tailwind CSS
- Supabase (lead storage)
- Google Sheets API (lead sync)
- SMTP Email Notification
- Vercel-ready

## Setup

1. Install dependencies
   - `npm install`
2. Create env file
   - `cp .env.example .env.local` (or create `.env.local` manually on Windows)
3. Run dev server
   - `npm run dev`

## Vercel Deployment

1. Import the repository into Vercel.
2. Keep the framework preset as `Next.js`.
3. Use the default build command:
   - `npm run build`
4. Add the required environment variables from [`.env.example`](C:\Users\dell\OneDrive\Desktop\2 page scopex web\.env.example) into the Vercel project settings.
5. Deploy.

The project is configured for Vercel auto-detection with:

- `next` as a direct dependency
- standard `dev`, `build`, and `start` scripts
- App Router structure under `app/`
- ESLint configured non-interactively

## Supabase Table (Suggested)

```sql
create table if not exists leads (
  id bigint generated by default as identity primary key,
  created_at timestamptz not null default now(),
  lead_type text not null,
  name text not null,
  age int null,
  mobile_number text not null,
  whatsapp_number text null,
  purpose text null,
  source text null
);

create index if not exists leads_mobile_type_created_idx
on leads (mobile_number, lead_type, created_at desc);
```
